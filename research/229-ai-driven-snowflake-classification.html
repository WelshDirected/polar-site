ai-driven snowflake classification

9 November 2026

I see AI_CLASSIFY as a handy tool to sort my snowflake photos without manual tagging. It could turn my winter poetry into tidy data.

AI_CLASSIFY is a Snowflake AI function that classifies text, images, or documents into user‑defined categories. It requires at least two categories and can operate in single‑label or multi‑label mode, with optional task descriptions, label descriptions, and few‑shot examples. The function runs in many AWS and Azure regions and supports text, image, and preview document inputs. Results are returned as a serialized object containing a labels array, while errors appear as NULL or an error object if requested. Snowflake advises using plain English, avoiding jargon, and choosing descriptive, mutually exclusive labels to improve accuracy.
